# DSA_LabWork

A comprehensive repository for **Data Structures and Algorithms (DSA)** laboratory work and implementations in C.

## 📚 Overview

This repository serves as a learning resource and reference for implementing fundamental data structures and algorithms from scratch. It contains well-documented C code demonstrating core DSA concepts with practical examples and problem solutions.

## 🎯 What to Expect

### Current Content
- **Basic Data Structures**: Arrays, Linked Lists, Stacks, Queues
- **Advanced Structures**: Trees (BST, AVL), Graphs, Hash Tables
- **Sorting Algorithms**: Bubble Sort, Quick Sort, Merge Sort, Heap Sort, etc.
- **Searching Algorithms**: Linear Search, Binary Search
- **Graph Algorithms**: BFS, DFS, Dijkstra's, Floyd-Warshall
- **Dynamic Programming**: Classic DP problems and solutions

### Implementation Approach
- Clean, readable C implementations
- Detailed comments explaining logic and time/space complexity
- Memory-safe practices with proper allocation and deallocation
- Test cases for validation

## 🛠️ How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/satyamkr0808/DSA_LabWork.git
   cd DSA_LabWork
   ```

2. **Compile and run C programs**
   ```bash
   gcc -o program_name program_name.c
   ./program_name
   ```

3. **Study the implementations**
   - Read the comments and explanations
   - Trace through examples
   - Understand the complexity analysis
